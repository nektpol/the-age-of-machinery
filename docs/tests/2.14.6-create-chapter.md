## Completed acceptance procedure (reference only)

1. Run `gradlew.bat runClient`. Create a **fresh creative world with cheats** and enable `The_Age_of_Machinery_2.14.6_Create_Workshop.zip` in world creation's Data Packs screen. Keep the previous test world unchanged.
2. Skip only the already-tested prelude:

```mcfunction
/tamruntime progress gather_cobblestone 16
/tamruntime advance
/tamruntime progress craft_crafting_table 1
/tamruntime advance
/tamruntime player
```

3. The active quest should be **A Workshop in Motion**. Craft one Water Wheel (8 planks + 1 Shaft), place it yourself and run it using flowing water. Optional: craft one Cogwheel (1 Shaft + 1 plank) before advancing. Creative inventory can supply the ingredients.
4. Run `/tamruntime player`. Both mandatory objectives should be complete. Run `/tamruntime advance`; **The First Sheets** should become active.
5. Claim the first chapter's earned rewards:

```mcfunction
/tamruntime claim quest theageofmachinery:workshop_water_power main_xp
/tamruntime claim quest theageofmachinery:workshop_water_power main_alloy
```

Expect 40 XP points and 2 Andesite Alloy. Repeating either claim should be refused. If you completed the optional Cogwheel, `/tamruntime claim quest theageofmachinery:workshop_water_power bonus_craft_cogwheel` grants 10 XP points; otherwise that bonus is unavailable.

**Pass:** the new quest loads, real actions complete it, manual advancement selects the next quest, and earned rewards can be claimed once. No full survival playthrough or repeat of the 2.14.5 machine-hook tests is required for this check.
